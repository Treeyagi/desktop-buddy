# attention

The ADHD engine and random-event system. Pure local logic, no Claude usage.

- **Inputs:** desktop events from `desktop-awareness/`, timers, idle state
- **Outputs:** behavior and animation requests to `character/`
- **Behaviors:** attention targets, tangent mode, hyperfocus mode, squirrel moments (chase cursor), Kroger clearance-aisle sequence (pick up, daydream, do the math, put back or get excited), vending machine event (50/50 sad or joy, pity counter), heart-and-spirit walk-out moments
- **Notes:** vending machine art should be an original look-alike for anything shared publicly
