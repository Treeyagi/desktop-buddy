# voice-out

Text-to-speech in my cloned voice, plus the under-the-breath humming.

- **Inputs:** reply text from `brain/`, hum requests from `character/` while walking
- **Outputs:** audio playback, speaking-started and speaking-finished events
- **Notes:** local XTTS or F5-TTS. TODO: record voice samples in one quiet room with the same mic, in several moods (flat, annoyed, excited). Hums are short original loops (no licensed songs), very quiet, mutable during calls.
